## Development Principle

Stabilize one system at a time. Every milestone begins from a confirmed working ZIP, changes the smallest possible surface, and ends with an iPad interaction checklist.

## Release Checklist for Every Milestone

- Start from the documented baseline.
- Make a backup ZIP before editing.
- Run syntax checks and a fresh Vite build.
- Test fresh save and migrated save.
- Test iPad landscape, iPad portrait, and desktop.
- Test every control affected by the milestone.
- Update `PROJECT_STATE.md`, `ROADMAP.md`, `ARCHITECTURE.md`, and patch notes.
