# The Village V33.0.2 — Save Manager

Built directly from the confirmed working V33.0.1 Safe Master.

## Added
- One visible **Save Manager** tile in the More screen.
- Save Now with an immediate safety snapshot.
- Export Save to a portable JSON file.
- Import Save through the iOS/iPadOS Files picker.
- Automatic backup before import or restore.
- Restore Previous Backup.
- Save Information summary.
- Two-step confirmation for restore, import, and delete operations.
- Scroll-safe More screen and mobile Save Manager layout.

## Preserved
- Existing bottom navigation and its event wiring.
- Campaign progression, tower/card unlocks, resources, village plots, and legacy save keys.
- Living Village, citizens, weather, familiars, battle, and MGS Easter eggs.

## Validation
- JavaScript syntax checked with Node.
- ZIP structure checked after compilation.
