# V33.0.3 — Modular Cathedral

- Removed the duplicate foreground battle Keep that covered the original Cathedral.
- Preserved the original compact Cathedral as the single gate structure.
- Connected visual evolution directly to the existing `keepBattleLevel()` system.
- Keep Level 2 adds attached side defense towers.
- Keep Level 3 adds reinforced battlements and richer tower detailing.
- Keep Level 4 adds taller side towers and an upper central spire.
- Keep Level 5 adds royal trim, crown detailing, and final-tier materials.
- Visible archer defenders remain synchronized with the functional archer count.
- Damage cracks and low-health damage states remain active on the modular Cathedral.
- No changes to battle balance, saves, progression, cards, navigation, or Save Manager.
